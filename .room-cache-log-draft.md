## Yang dikerjakan

Endpoint `/api/panel/trial-model` memakai validator ETag untuk room dan texture berdasarkan model, revision, dan ID aset. Browser dapat menyimpan respons secara private dan harus memvalidasinya kembali pada setiap request. Server tetap memeriksa revision aktif sebelum mengembalikan 304; aset yang tidak ada tetap 404. Cache snapshot satu revision per proses yang sudah ada tetap digunakan.

## Solution terkait

[[03-Solutions/SOL-0006-lby-share-link-import-dan-rollback|Import LBY dan snapshot berversi]] menjadi referensi identitas revision dan aktivasi. [[05-Projects/trackerprod/_overview|TrackerProd overview]]

## Hasil

`node tests/trial-location-access.cjs` lulus untuk 304 room/texture, validator berbeda, aset hilang, dan revision nonaktif. `node node_modules/typescript/lib/tsc.js --noEmit --pretty false` serta `git diff --check` lulus.

## Keputusan / langkah berikutnya

Belum diukur pada browser atau deployment. Kunjungan pertama tetap mengunduh aset; rendering 3D tetap dibuat ulang saat berganti room. Endpoint preview admin dan model lama tidak diubah.
